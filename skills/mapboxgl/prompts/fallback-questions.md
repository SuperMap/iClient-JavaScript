# 补问问题 - 缺失参数

## 场景 1：缺少 iServer URL

**触发条件**：意图为 LOAD_MAP 但未提供 URL

**提示词**：
```
我需要 iServer 地图服务的地址来加载地图。

请提供以下格式的地址之一：
• 完整地址: https://iserver.supermap.io/iserver/services/map-china400/rest/maps/China
• 仅服务名: map-china400 (我会自动补充完整路径)

如果您有正在运行的 iServer，可以从以下位置获取地址：
1. iServer 管理界面 → 服务管理 → 选择地图服务
2. 复制服务的根地址（直到 /rest/maps/ 为止）
```

---

## 场景 2：缺少中心点

**触发条件**：意图为 LOAD_MAP，URL 有效，但未提供中心坐标

**提示词**：
```
地图服务地址已确认。
您想以哪个位置为中心显示地图？

选项：
1. 使用城市名: 如 "北京"、"上海"、"深圳"
2. 使用坐标: 如 [116.4, 39.9] (经度, 纬度)
3. 使用默认值: 我将使用地图服务的默认中心点

请告诉我您想让地图中心显示在哪里？
```

**城市快速参考**：
| 城市 | 坐标 |
|------|------|
| 北京 | [116.39, 39.9] |
| 上海 | [121.47, 31.23] |
| 广州 | [113.26, 23.13] |
| 深圳 | [114.05, 22.55] |

---

## 场景 3：缺少缩放级别

**触发条件**：意图为 LOAD_MAP，URL 和中心点有效，但未提供缩放级别

**提示词**：
```
好的，地图将以 [Lng, Lat] 为中心显示。

您想显示多大范围的地图？

选项：
1. 全国/全省范围 → 缩放级别 4-6
2. 全市/全区域范围 → 缩放级别 8-10
3. 街道/详细范围 → 缩放级别 12-15

例如：
• "显示全国" → zoom: 4
• "放大到市级" → zoom: 8
• "显示详细街道" → zoom: 14

请告诉我需要的缩放级别，或描述您想显示的范围。
```

---

## 场景 4：查询时缺少数据集名称

**触发条件**：意图为 QUERY_ANALYSIS 但未提供数据集名称

**提示词**：
```
您想查询哪个数据集的数据？

请提供以下信息之一：
1. 完整数据集名: World:Countries 或 Countries@World
2. 数据服务地址: 我会列出可用的数据集

iServer 数据服务地址格式：
https://iserver.supermap.io/iserver/services/data-world/rest/data

请提供您要查询的数据集名称或数据服务地址。
```

---

## 场景 5：缺少缓冲距离

**触发条件**：请求了缓冲区分析但未提供距离

**提示词**：
```
您想设置多大的缓冲半径？

常见选项：
• 步行距离: 500米 - 1公里
• 骑行距离: 2-5公里
• 驾驶距离: 10-50公里

请告诉我缓冲半径的数值和单位，例如：
• "500米"
• "2公里"
• "1000" (默认单位为米)

---

## 场景 6：地图操作缺少目标参数

**触发条件**：意图为 MAP_OPERATIONS 但未提供目标坐标或缩放级别

**提示词**：
```
请提供地图操作的目标参数：

1. 目标中心点: 经纬度坐标，如 [116.4, 39.9]
2. 缩放级别: 如 10（市级）、14（街道级）
3. 或描述操作意图: 如 "飞到北京"、"放大到街道级别"
```

---

## 场景 7：无法识别的服务 URL 类型

**触发条件**：已提供 URL 但无法判断服务类型（REST Map / REST Data / Spatial Analyst）

**提示词**：
```
您提供的服务地址我无法自动判断服务类型。请确认这是哪种服务：

1. REST 地图服务 → 地址格式: .../rest/maps/{mapName}
2. REST 数据服务 → 地址格式: .../rest/data
3. 空间分析服务 → 地址格式: .../restjsr/spatialanalyst
4. WMTS 服务 → 地址格式: .../wmts-xxx
5. WMS 服务 → 地址格式: .../ogc/wms/{mapName}
```

## 通用补问模板（自动化使用）

当参数校验检测到缺失或类型不匹配时，建议使用以下模板生成精确问题：

- 参数缺失（示例）
```
我需要参数 `{{paramName}}` 才能继续（例如：{{example}}）。
请提供 `{{paramName}}` 的值，或回复 "使用默认值" 以采用 `{{default}}`。
```

- 单位不明确（示例）
```
您提供的值是 `{{value}}`，但未指定单位。
请确认单位是：米 / 公里 / 度（经纬度）中的哪一种？
例如："500米" 或 "0.5 公里"。
```

- 参数类型不符（示例）
```
参数 `{{paramName}}` 期望类型为 `{{expectedType}}`，但收到 `{{receivedValue}}`（类型：{{receivedType}}）。
请提供符合类型的值，例如：{{example}}。
```

- 操作确认（示例）
```
我将按以下方式执行：
- 操作: {{operation}}
- 目标图层/数据集: {{dataset}}
- 参数: {{params}}

是否确认继续？（回复 "确认" 或列出需要修改的项）
```

这些模板可由决策层自动填充并发送，以缩短来回交互并提高参数收集的精确度。
```
