# 坐标系叠加规则

## 坐标系要求

| 图层类型 | 坐标系要求 |
|----------|------------|
| 底图（initMap） | 支持多坐标系（EPSG:3857、EPSG:4326、地方坐标系等） |
| GeoJSON | 只能是 WGS84（EPSG:4326） |
| 栅格瓦片叠加 | 必须与底图投影一致 |
| 矢量瓦片叠加 | 必须与底图投影一致 |

## 默认坐标系

- **默认底图投影**：Web 墨卡托（EPSG:3857）
- **GeoJSON**：必须是 WGS84（EPSG:4326）

## 叠加规则

1. 其他叠加的**栅格瓦片**、**矢量瓦片**只能和底图投影一致，否则无法正确叠加
2. **GeoJSON** 必须是 WGS84 坐标系，如果数据使用其他坐标系（如 EPSG:3857），需要先转换为 WGS84 才能叠加到地图上

## 非标准坐标系处理

- 非 EPSG:3857/EPSG:4326 坐标系需要添加 `&scale={scale}` 参数
- 需要引入 mapbox-gl-enhance 库以支持自定义坐标系（CRS）
- CRS 格式：`new mapboxgl.CRS('EPSG:2362', WKT, [left, bottom, right, top])`
