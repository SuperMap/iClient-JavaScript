# 缺少必要信息时的补充问题

仅询问生成用户所需可运行示例必不可少的信息。如果用户没有服务 URL，可提供基于公开 World REST 地图的可运行示例。

| 缺少的信息 | 问题 |
|---|---|
| iServer 地图 URL | “请提供 iServer REST 地图服务地址（`/rest/maps/{地图名}`），还是先用公开的 World 地图服务生成可运行示例？” |
| REST Data 查询 | “请提供 REST Data 服务地址、数据集名称，以及需要的查询条件。” |
| REST Map 查询 | “请提供 REST Map 服务地址、图层名称和查询条件。” |
| MVT 矢量瓦片数据源 | “请提供瓦片服务地址、图层标识、坐标系和 `source-layer` 名称。” |
| WMTS 栅格瓦片 | “请提供 WMTS 服务地址和要加载的图层标识；Capabilities 可读取图层及瓦片矩阵信息。” |
| WMS 栅格图层 | “请提供 WMS 服务地址和要加载的图层名称；Capabilities 可读取版本、样式、图像格式及支持的坐标系。” |
| 空间分析 | “请提供分析服务地址、输入数据/几何、分析类型和必要参数。” |
| 非标准投影 | “请提供 EPSG/WKT、数据范围，以及是否允许加载 MapLibreGL enhance 扩展。” |

可使用已有示例默认值的信息无需追问。不要编造凭据、服务端点、图层标识或分析参数。
